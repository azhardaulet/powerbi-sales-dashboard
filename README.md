# powerbi-sales-dashboard
## Цель проекта:

Построить интерактивный дэшборд для анализа данных о продажах, чтобы определить самые прибыльные товары, категории и регионы, а также отследить динамику продаж по годам.

## О данных:

Датасет содержит информацию о заказах интернет-магазина за 2014–2017 гг.: дата заказа и доставки, сегмент клиента, регион, город, категория и подкатегория товара, количество, сумма продаж (Sales) и прибыль (Profit).

### Что сделано:

- Рассчитаны ключевые показатели: общая сумма продаж (2 297 200,86), общая прибыль (286,40 тыс.), количество заказов (9994).

- Построена динамика прибыли по годам (2014–2017) в разрезе сегментов клиентов (Consumer, Corporate, Home Office).

- Визуализирована прибыль по регионам (West, East, South, Central) в виде круговой диаграммы, а также максимум/минимум прибыли по каждому региону.

- Определены самые прибыльные штаты (California, New York, Washington, Michigan, Virginia).

- Построен рейтинг товаров по сумме продаж (топ — Canon imageCLASS 2200 Advanced Copier).

- Проанализированы продажи по категориям и подкатегориям товаров.

- Настроены интерактивные фильтры: категория товара, дата заказа, дата доставки, сегмент, регион, город, тип доставки, название продукта.


### Ключевые выводы:

- Наибольшую долю прибыли приносит регион West (37,86%), наименьшую — Central (13,86%)

- Продажи стабильно растут год к году: с 49,54 тыс. в 2014 до 93,44 тыс. в 2017 (прибыль по сегментам).

- Основной вклад в продажи вносит категория Technology, при этом отдельные товары (копиры, переплётное оборудование) формируют значительную часть выручки.

- Штат California заметно опережает остальные по объёму прибыли.
